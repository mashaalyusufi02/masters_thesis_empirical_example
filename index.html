Key steps in the US states unemployment rate script

  • Extract monthly time series data of the unemployment rate for 50 US states using the fredr() package.
  • Tidy unemployment rate data, remove missing values, and standardize it.
  • Fit an ARIMA model to the time series of each US state and extract the residuals.
  • Fit a Gaussian Graphical Model to the residuals of the ARIMA model.
  • Transform the residuals and fit a Gaussian Graphical Model again.
  • Produce two maps that display the edges of the Gaussian graphical model before and after the transformation.

Key Visuals

Histograms - Residuals of an ARIMA model fitted to unemployment rate of selected U.S States

The residuals represent the difference between the actual and fitted values to the unemployment rate of 50 US states between 1980 and 2025. Notice how the histogram displays residuals that are right-skewed.

Maps - Edges between unemployment rate residuals of 50 US States.

  • Each map displays the conditional dependence structure between unemployment rates for all 50 states.
  • The map labelled ‘NPN Graph Threshold = 0.95’ displays the edges in the model post–residual transformation.
  • The map labelled “GGM Graph threshold = 0.95” displays the edges in the model prior to the transformation.
  • The map showing the edges of the transformed residuals has fewer edges and therefore captures more true relationships than the untransformed residuals.
